## 2024-05-18 - String Generation Micro-optimizations
**Learning:** In V8, when iterating through strings character by character in tight loops, caching properties like `length` prevents property access overhead and yields a considerable performance boost. Additionally, using bracket notation (e.g. `chars[i]`) instead of `charAt(i)` for string character lookup within hot loops further reduces execution time by avoiding string method call overhead. Another critical optimization here: allocating large blocks of random data via `new Uint8Array(length)` is significantly faster than iteratively dynamically pushing elements via `Array.prototype.push`.
**Action:** Always pre-allocate fixed-length typed arrays like `Uint8Array` when generating byte arrays. Within hot generation/processing loops, proactively cache array/string lengths and utilize bracket access for maximum string interpolation speed.
