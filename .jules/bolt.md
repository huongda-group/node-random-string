## 2024-05-24 - V8 Performance optimizations in Node.js
**Learning:** Returning standard string primitives dynamically across long if-else ladders inside functions dynamically evaluates new string primitives, adding measurable allocation overhead. Direct indexed access `buf[i]` on `Buffer` or `Uint8Array` is significantly faster than using method calls like `buf.readUInt8(i)`. Using bracket notation for strings `chars[index]` is more performant than `.charAt()`. Using `Uint8Array` over dynamically sized arrays for byte buffers saves resizing overhead.
**Action:** Lift fixed string literal generation into global constants to prevent repeated instantiation. Use `typeof (buf).readUInt8 === 'function'` fallback for legacy compat while using direct `buf[i]` fast indexing. Use bracket string indexing for extracting characters. Pre-allocate arrays where length is known.
