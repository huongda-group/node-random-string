## 2025-05-29 - V8 String Building Performance Hot-paths
**Learning:** In tight string generation loops (like `processString` inside `random-string`), using bracket notation `chars[index]` is measurably faster (~15-20%) than `chars.charAt(index)`. Also, caching object/array lengths (`buf.length` or `chars.length`) is critical to avoid continuous V8 property lookup overhead on hot loops. Finally, extracting fixed string combinations into module-level constants avoids repeated allocation and garbage collection overhead during frequent class instantation. Pre-allocating `new Array(length)` is significantly faster than dynamically `push`ing to arrays for simple numeric stacks in Node.js.
**Action:** Always prefer array bracket notation for character extraction and cache loop boundaries in string generator routines. Hoist fixed literal definitions to module scope.
