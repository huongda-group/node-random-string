
## 2024-05-18 - Hot path allocation, prototype lookup, and array access overhead
**Learning:** In tight random string generation loops, three specific micro-optimizations proved effective in V8. 1. Using a dictionary map (`Object.create(null)`) for simple static string lookups avoids long if/else chains and prototype resolution overhead. 2. Replacing `.charAt()` with bracket notation `[]` provides a measurable speedup. 3. Node buffers expose array-like indexing which avoids the function call overhead of `.readUInt8(i)`, further optimizing array iteration. Furthermore, avoiding `.split()` and `Set` operations in simple string deduplication routines saves significant allocation overhead.
**Action:** When working on generating functions within a loop, aggressively cache array/buffer lengths, prioritize bracket notation over `.charAt()`, use index-based `for` loops over functional approaches, fallback to direct array index access on buffers (`buf[i]`), and use `Object.create(null)` for simple string mapping caches instead of conditionals or standard object literals to prevent prototype interference.
