## 2024-05-22 - Optimize getCharacters and ProcessString with Constant Lookups and Bracket Notation
**Learning:** Object mapping lookups actually add overhead in V8 compared to a simple if-else switch with hardcoded constants in this codebase's hot paths. Additionally, extracting fixed string literal generation out of standard functions prevents repeated instantiation costs. Finally, bracket notation combined with cached lengths and `.readUInt8` natively works well to improve buffer processing over charAt.
**Action:** Replace `getCharacters` inner allocations with module-level or literal constants for simple character retrieval. Keep bracket notation (`chars[index]`) + length caching in the `processString` loop. For fallback `safeRandomBytes`, switch fallback buffer array creation from `[]` push to `new Array(length)` to improve fallback perf.
