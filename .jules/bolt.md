## 2024-06-25 - Extracted Constant Literals and Pre-allocated Arrays for Node.js String Generation
**Learning:** In a highly-called utility function generating random strings, object instantiation overhead matters. In V8 (Node.js), mapping simple strings via an object lookup is actually slower than a switch block with module-level constants. Also, bracket notation (`chars[index]`) is slightly faster than `.charAt()` inside string concatenation loops, and dynamic array pushes (`[]` then `.push()`) for creating byte arrays have unnecessary allocation overhead compared to pre-allocating a typed array (`new Uint8Array(length)`).
**Action:** When writing utilities involving string and array generation in tight loops or paths called millions of times, extract static values into module-level constants to avoid instantiation costs, cache array bounds (`.length`) locally, use direct bracket access for strings over `.charAt()`, and prefer explicitly sized arrays or typed arrays (e.g. `Uint8Array`) over dynamically resizing ones.
