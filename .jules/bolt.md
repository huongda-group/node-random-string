## 2024-05-17 - Allocation overhead and String lookups
**Learning:** In a heavily invoked utility for random string generation, allocation overhead from dynamic arrays and Set conversions become significant bottlenecks. Utilizing a simple string iteration with `indexOf` for deduplication and replacing string switch cases with a pre-allocated object map dictionary proved significantly more performant than ES6 abstractions. Additionally, generating `Uint8Array` directly is faster than dynamically pushing to standard arrays.
**Action:** When working on hot string/array generation routines, avoid mapping and conversion features (like Set or spread operator) that create overhead. Prefer straightforward pre-allocated data structures and dictionary mappings with `Object.create(null)` for fast O(1) lookups.
