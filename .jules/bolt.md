## 2025-02-28 - Optimizing allocation and dictionary access in tight loops
**Learning:** In a highly iterated string generation process (like random string algorithms), small V8 overheads compound quickly. Repeatedly creating identical strings and checking multiple `if`/`else` branches (or instantiating new primitive sets in an array) inside hot functions creates unnecessary garbage collection pauses and slows down execution.
**Action:** Next time, define simple configuration maps (e.g. constant charset mappings) at the module level using `Object.create(null)` to skip prototype lookups and re-allocations. In tight generation loops, avoid high-allocation methods like `.split()`, `.join()`, and `new Set()` for small dataset de-duplication, opting instead for a classic `for` loop with `.indexOf()`.
