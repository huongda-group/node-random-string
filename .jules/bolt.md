## 2024-10-24 - Node Buffer Direct Array Access Fast Path in Tight Loops
**Learning:** In tight Node.js loops involving dynamic string/byte concatenation over `Buffer`, using direct indexed access (`buf[i]`) and string bracket access (`chars[index]`) is measurably faster than the `buf.readUInt8(i)` and `chars.charAt()` counterparts. However, for polyfills and Duck-typed structures (`UnsafeBuffer`), safe fallback is necessary, requiring explicit checks like `typeof buf[0] === 'number'`. Pre-allocating `Array` via `new Array(length)` is additionally significantly faster than dynamically calling `.push()` in loops when generating mocked fallback random bytes in pure JS environments.
**Action:** Next time when working with repeated iterations over buffers or mocked buffers across Node and edge environments, pre-allocate arrays directly and explicitly define duck-typed paths to prefer direct index access for massive speedups on hot loops.
