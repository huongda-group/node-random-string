## 2024-05-16 - Array and Allocation Overhead in Random String Generation
**Learning:** In a utility module like `random-string`, random byte generation and tight character mapping loops are extremely sensitive to object allocation and repeated property lookups. Constructing unique sets `[...new Set(arr)]`, using `.charAt()`, and pushing values sequentially into a standard JavaScript array `[]` cause noticeable overhead in Node.js.
**Action:** Next time I work on high-throughput string generation algorithms, I will favor `Uint8Array` over standard arrays for byte storage to prevent dynamic resizing, use a simple `indexOf` loop instead of `Set` + Array mapping for small-string deduplication, and prefer bracket notation `str[idx]` with cached `.length` values in character lookup loops to minimize V8's overhead.
