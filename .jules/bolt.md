## 2024-06-19 - Fast Random String Generation
**Learning:** In hot loops involving random string generation, standard Javascript operations incur overhead. Specifically, repeatedly instantiating strings across method calls (like inside a `.getCharacters()` class method) allocates memory that builds up in tight loops. Furthermore, reading characters from a string using `.charAt(index)` is slower than bracket notation (`[index]`). Lastly, dynamically pushing elements into `number[]` array during pseudo-random byte generation is significantly slower than pre-allocating a `Uint8Array(length)`.
**Action:** When working on string generation utility methods that are called thousands of times: 1. Extract static string literals to module-level constants. 2. Use bracket notation (`string[index]`) instead of `.charAt(index)`. 3. Cache lengths of buffers/strings accessed inside tight loops. 4. Pre-allocate typed arrays (like `Uint8Array`) when generating fixed-size numeric/byte sequences instead of dynamically sizing Javascript arrays.
