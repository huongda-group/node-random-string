## 2024-05-23 - Micro-optimizing string generation loops in JS/TS
**Learning:** In tight loops involving string character access and appending, bracket notation (e.g. `chars[index]`) is consistently faster than using the `.charAt()` method in V8. Additionally, repeatedly allocating arrays for byte generation adds measurable overhead compared to pre-allocating typed arrays like `Uint8Array(length)`. Finally, generating constants dynamically via string concatenation for simple fixed choices (like character sets) adds non-trivial constant factor cost that can be bypassed entirely with pre-computed literals.
**Action:** When working on hot path string generation functions, always cache `.length` accesses, prefer bracket notation for strings, avoid inline `.push` for array initialization by replacing with pre-allocated typed arrays, and return pre-computed static strings instead of dynamically concatenating variables.
